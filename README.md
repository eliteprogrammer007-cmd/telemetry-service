# telemetry-service

Part of the Orbital Horizons Labs public engineering repositories.

Collects simulator telemetry frames and forwards normalized events to mission
control dashboards.

## Local development

Copy `.env.example` to `.env` and use simulator tokens from the internal vault.
The public repository must not contain production credentials.
